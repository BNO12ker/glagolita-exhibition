# Glagolita kiállítás – GitHub Pages site

Ez egy statikus weboldal a feltöltött kiállítási PDF alapján.

## Feltöltés GitHub-ra

1. Hozz létre egy új repository-t, például: `glagolita-exhibition`
2. Töltsd fel a teljes mappa tartalmát a repository gyökerébe.
3. GitHubon menj ide: **Settings → Pages**
4. Source: **Deploy from a branch**
5. Branch: **main**, folder: **/(root)**
6. Mentés után a site címe várhatóan:
   `https://YOUR-USERNAME.github.io/glagolita-exhibition/`

## Fontos QR-kód lépés

A QR-kódok most ezt a sablon URL-t tartalmazzák:

`https://YOUR-USERNAME.github.io/glagolita-exhibition`

Cseréld le a saját GitHub felhasználónevedre, majd generáld újra a QR-kódokat, vagy szólj, és megadott GitHub felhasználónév/repository alapján elkészítem újra.
